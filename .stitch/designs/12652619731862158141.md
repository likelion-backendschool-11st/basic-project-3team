## 1. 디자인 콘셉트

- **키워드**: 네오브루탈리즘, 굵은 검정 테두리, 딱딱한 그림자, 노랑 포인트, 개발자 감성(모노 폰트)
- **느낌**: 장난스럽지만 정돈된 화면. 종이 위에 스티커를 붙인 것처럼 요소가 또렷하게 떠 보인다.
- **원칙**
  1. 모든 카드·버튼·입력창은 **검정 2.5px 테두리**를 가진다.
  2. 그림자는 흐림(blur) 없이 **오른쪽 아래로 밀린 단색 검정**만 쓴다.
  3. 색은 적게 쓴다. 노랑(강조)·파랑(행동)·빨강(위험) 세 가지만 의미를 가진다.
  4. 코드·태그·숫자는 모노 폰트로 개발자 서비스임을 드러낸다.

## 5. 컴포넌트

### 5-1. 버튼
| 종류 | 스타일 | 사용처 |
|---|---|---|
| 기본 | 흰 배경 + 검정 테두리 + 작은 그림자 | 취소, 보기, 중복확인 |
| Primary `.p` | 파랑 배경 + 흰 글자 | 질문하기, 등록, 로그인, 저장 |
| Yellow `.y` | 노랑 배경 | 채택하기, 내 닉네임 버튼, 데모 버튼 |
| Danger `.d` | 빨강 배경 + 흰 글자 | 삭제, 신고하기, 추방 |
| 선택됨 `.on` | 검정 배경 + 흰 글자 | 정렬 탭(인기순/최신순), 현재 메뉴 |
| 작은 `.sm` | 패딩 4×10, 평소 그림자 없음 | 탭, 표 안 버튼, 좋아요 |

- **Hover**: `translate(-1px,-1px)` + 그림자 `4px 4px 0`로 살짝 떠오름
- **Active(누름)**: `translate(3px,3px)` + 그림자 없음 → 눌리는 느낌
- **Disabled**: 투명도 45%, 그림자 없음 (예: 답변 10자 미만일 때 등록 버튼)

### 5-2. 카드
- 흰 배경 + 테두리 + 큰 그림자 + 모서리 12px
- **노랑 패널 카드**: 로그인 박스, 사이드 인사 카드, 등급 요약, 태그 결과 헤더
- 리스트 카드는 안쪽 여백 0, 행 사이를 2px 검정선으로 구분

### 5-3. 입력창
- 흰 배경, 테두리 2.5px, 모서리 10px, 패딩 9×12
- **Focus**: 작은 그림자 + 배경 `#FFFEF3`
- 본문 textarea는 모노 폰트 13px, 최소 높이 200~260px
- 하단 메시지 3단계: 회색 `.hint`(안내) / 초록 `.okmsg`(성공) / 빨강 `.err`(오류)
- 글자 수 카운터는 오른쪽 아래 (예: `6/50`, 한도 도달 시 빨강)

### 5-4. 태그 · 뱃지
- **태그**: 모노 12px, `#spring` 형식, 흰 배경 + 테두리, hover 시 노랑. 선택된 태그는 노랑 배경
- **뱃지**: 둥근 알약 모양 11px 굵게. `채택 완료`는 초록, `처리 대기`는 노랑, `정지·추방`은 빨강

### 5-5. 닉네임 + 등급 표시
```
자바초보 ★   1년차 · Java · 브론즈 · 채택률 40%
```
- 프로필 사진(아바타)은 쓰지 않는다.
- 닉네임 오른쪽에 등급 색 ★. "등급", "Lv." 같은 글자는 붙이지 않는다.
- 메타 순서: **연차 · 개발 언어 · 등급명(등급 색) · 채택률**
- 닉네임 클릭 → **작성자 요약 카드** (팝오버, 폭 280px): 닉네임+★, 메타, 소개, 질문/답변/채택 수(3칸 통계), 뱃지. ESC 또는 바깥 클릭으로 닫힘

### 5-6. ⋮ 더보기 메뉴
- 작성자와 관리자에게만 보인다.
- 펼침 메뉴: 흰 배경 + 테두리 + 작은 그림자, 항목 hover 시 노랑
- 항목: `✏ 수정`, `🗑 삭제`(빨강). 관리자는 `🗑 삭제 (관리자)`만
- 채택된 답변에는 메뉴를 숨긴다 (수정·삭제 불가).

### 5-7. 모달 · 팝업
- 배경: 어둡게 하지 않고 **블러 처리** — `rgba(255,253,245,.55)` + `backdrop-filter: blur(8px)`
- 박스: 폭 최대 440px, 큰 그림자 `8px 8px 0`, 우측 상단 ✕
- 버튼은 오른쪽 정렬: `[취소] [확인/삭제]`
- 삭제 확인 문구는 이중 확인: "삭제한 질문과 답변은 **복구할 수 없어요**. 정말 삭제하시겠어요?"
- 신고 모달: 사유 7개 라디오(스팸/광고, 욕설/비방, 음란물, 개인정보 노출, 도배, 저작권 침해, 기타) + 기타 선택 시 입력창

### 5-8. 토스트
- 화면 하단 중앙, 검정 배경 + 흰 글자 + 흰 테두리 + 큰 그림자, 2.2초 후 사라짐
- 예: "답변을 채택했어요 (+5P)", "이미 신고한 게시물이에요"

### 5-9. 헤더
- 흰 배경, 하단 2.5px 검정선, 스크롤 시 상단 고정
- 왼쪽 로고 `Dev [in_]` / 가운데 검색(범위 셀렉트 + 입력창) / 오른쪽 `+ 질문하기`(파랑) · 🔔(안 읽은 수 빨강 뱃지) · `닉네임 ★ ▾`(노랑)
- 검색 포커스 시 드롭다운: 검색 범위, 인기 태그, 최근 검색어(× 삭제)

### 5-10. 기타
- **코드블록**: 배경 `#111`, 글자 `#E6EDF3`, 키워드 `#FF7B72`, 어노테이션 `#D2A8FF`, 주석 `#8B949E`, 가로 스크롤
- **페이지네이션**: 30×30 정사각 버튼, 현재 페이지 파랑, 최대 5개 + `‹ ›`
- **토글 스위치**: 44×24, ON 파랑, 손잡이 흰 원 + 검정 테두리
- **진행바**: 높이 14px, 둥근 테두리, 채움 파랑 (등급 진행도)
- **표**: 칸마다 2px 검정 테두리, 헤더 노랑
- **뱃지 아이콘**: 56px 원형 노랑. 미획득은 회색 점선 + 투명도 50%
- **답글**: 왼쪽 3px 노랑 세로선 + `↳`, 한 단계만 (답글의 답글 없음)
- **채택 답변**: 초록 배경 카드, 맨 위 고정. 정렬은 채택 → 좋아요 → 최신

## 6. 상태 화면

| 상태 | 표현 |
|---|---|
| 로딩 | 파랑 회전 스피너 + "불러오는 중이에요…" |
| 빈 목록 / 검색 결과 없음 | 🔍 + "'검색어'에 대한 결과가 없어요" + `[질문하기]` |
| 답변 없음 | 💭 + "아직 답변이 없어요" (작성자에겐 "답변이 달리면 알림으로 알려드릴게요") |
| 에러 | ⚠️ + "일시적인 오류가 발생했어요" + `[메인으로] [다시 시도]` |
| 404 | 큰 모노 `404`(노랑 그림자) + "페이지를 찾을 수 없어요" |
| 권한 없음 | 🔒 + "접근 권한이 없어요" |

- 로그인이 기본 전제다. 비로그인 상태의 UI(로그인 유도 등)는 만들지 않는다.

## 7. 반응형 (900px 이하)

- 2단 레이아웃 → 1단 (사이드바는 본문 아래로)
- 헤더 줄바꿈: 로고·버튼 한 줄, 검색창은 아래 줄 전체 폭
- 리스트 통계(좋아요·답변·조회)는 세로 → 가로 한 줄
- 표는 최소 폭 720px 유지 + 가로 스크롤
- 제목과 ⋮ 메뉴는 줄바꿈하지 않고 같은 줄 유지
- 토스트는 하단에서 80px 위로 올림 (데모 버튼과 겹침 방지)
