# Neo-Brutalism Design System & Concept Guide

네오브루탈리즘(Neo-Brutalism 또는 Neubrutalism)은 전통적인 미니멀리즘과 플랫 디자인의 절제된 규칙을 깨부수고, 대담한 원색, 두꺼운 외곽선, 하드 섀도우(Hard Shadow), 레트로한 타이포그래피를 결합하여 강렬한 개성과 생동감을 전달하는 현대적인 웹/모바일 UI 디자인 스타일입니다.

---

## 1. 핵심 철학 (Core Philosophy)

1. **대담함과 솔직함 (Bold & Raw)**
   - 부드러운 그라데이션이나 은은한 블러(Blur) 효과를 배제하고, 시각적 요소를 정직하고 선명하게 드러냅니다.
2. **명확한 구분과 경계 (High Contrast & Boundaries)**
   - 모든 컴포넌트(카드, 버튼, 입력창 등)는 굵고 진한 외곽선으로 감싸져 독립된 블록 형태로 표현됩니다.
3. **유쾌한 레트로 키치 (Playful & Retro)**
   - 90년대 윈도우 OS, 팝아트, 인쇄물 포스터 감성을 현대적인 모바일/웹 인터랙션과 결합합니다.

---

## 2. 컬러 팔레트 (Color Palette)

네오브루탈리즘은 채도가 높고 선명한 네온/비비드 컬러를 키 컬러로 사용하며, 배경과 외곽선에는 극명한 대비를 주는 순수 블랙과 웜 화이트를 매칭합니다.

| 분류 | 컬러명 | HEX 코드 | 설명 & 용도 |
| :--- | :--- | :--- | :--- |
| **Borders & Text** | Pure Black | `#000000` | 모든 보더(Border), 메인 텍스트, 단단한 그림자 |
| **Base Background** | Off-White / Cream | `#FFFDF0` | 부드럽고 따뜻한 종이 질감의 기본 배경 |
| **Primary Accent** | Electric Yellow | `#FFE600` | 핵심 CTA 버튼, 하이라이트 배지 |
| **Secondary Accent** | Vivid Coral Pink | `#FF5C8A` | 포인트 액션, 태그, 알림 |
| **Tertiary Accent** | Hyper Lime | `#A3FF00` | 성공 상태, 가격표, 키워드 강조 |
| **Accent Sky** | Retro Cyan | `#00D2FF` | 링크, 서브 배지, 정보 안내 카드 |
| **Neutral Surface**| White | `#FFFFFF` | 카드 및 폼 내부 배경 |

## 3. 타이포그래피 (Typography)

볼드하고 기하학적인 산세리프(Geometric Sans) 폰트를 기본으로 하며, 디스플레이용으로 무게감 있는 블랙/헤비 웨이트를 사용합니다.

- **Primary Font**: `Public Sans`, `Plus Jakarta Sans`, `Inter`, `Space Grotesk`
- **Monospace Font (Code/Details)**: `JetBrains Mono`, `Space Mono`

### 타이포 스케일 (Type Scale)

- **Display 1**: `36px` / Line Height `110%` / Weight `900 (Black)` — 메인 헤드라인
- **Heading 1**: `28px` / Line Height `120%` / Weight `800 (Extra Bold)` — 섹션 타이틀
- **Heading 2**: `22px` / Line Height `130%` / Weight `700 (Bold)` — 카드 제목
- **Body Large**: `16px` / Line Height `150%` / Weight `500 (Medium)` — 리드 텍스트
- **Body Regular**: `14px` / Line Height `150%` / Weight `400 (Regular)` — 본문 설명
- **Label / Button**: `14px` / Line Height `100%` / Weight `700 (Bold)` / Uppercase — 버튼, 배지

---

## 4. 컴포넌트 스타일 규칙 (Component Rules)

### 4.1 보더 및 라운딩 (Borders & Radius)
- **Border**: `3px` 또는 `4px` 실선 (`border: 3px solid #000000;`)
- **Border Radius**: 
  - 각진 형태: `0px` (완전한 박스형)
  - 또는 라운드 사각: `8px` ~ `12px` (알약형 필 버튼은 `9999px`)

### 4.2 그림자 규칙 (Hard Drop Shadow)
- 흐림(blur)이 없는 100% 불투명 솔리드 블랙 그림자를 우측 하단으로 투영합니다.
- **기본 카드**: `box-shadow: 4px 4px 0px #000000;`
- **강조 모달/플로팅**: `box-shadow: 6px 6px 0px #000000;`
- **호버 및 액티브 인터랙션**:
  - Hover: 위치가 위/좌측으로 이동하며 그림자가 커짐 (`translate(-2px, -2px)`, `box-shadow: 6px 6px 0px #000000;`)
  - Active (Click): 그림자 방향으로 완전히 눌림 (`translate(4px, 4px)`, `box-shadow: 0px 0px 0px #000000;`)

### 4.3 버튼 (Buttons)
- **Primary CTA**: `#FFE600` 배경 + `3px solid #000` + `4px 4px 0px #000` 그림자 + 볼드 텍스트.
- **Secondary**: `#FFFFFF` 배경 + `3px solid #000` + `3px 3px 0px #000` 그림자.

### 4.4 배지 및 태그 (Badges & Chips)
- 작고 컴팩트하며, 채도 높은 배경색(`#FF5C8A`, `#A3FF00`, `#00D2FF`)과 `2px solid #000`, `2px 2px 0px #000` 그림자 적용.

## 6. 적용 시 주의사항 (Dos & Don'ts)

- **DO**: 고대비 색상 조합으로 가독성을 확보하고 명확한 인터랙션 피드백(클릭 시 눌리는 감각)을 제공하세요.
- **DO**: 스티커, 볼드한 이모지, 기하학적 별표(★)나 화살표(→) 아이콘을 적극적으로 활용해 유쾌한 톤을 살리세요.
- **DON'T**: 텍스트와 배경의 명도 대비가 떨어지는 네온 컬러 위에 흰색 텍스트를 얹지 마세요 (항상 블랙 텍스트 권장).
- **DON'T**: 부드러운 블러 그림자(Blur/Spread)나 그라데이션을 섞어 본래의 날카롭고 솔직한 감성을 해치지 마세요.
